# Cuboid Surface Knight's Tour — 直方体表面のナイトツアー

**直方体（箱）の表面**を舞台にしたナイトツアー パズルです。
ナイトは面と面をまたいで移動し、箱の全マスをちょうど 1 回ずつ通る経路を目指します。
Three.js による 3D 表示で、箱を回転させながらプレイできます。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/Cuboid-Surface-Movement-Night-Tour
- デモ: https://sora3141.github.io/Cuboid-Surface-Movement-Night-Tour/

## 概要

- 直方体の 6 面をつなげた盤面上でのナイトツアー。辺をまたいだ移動が独特。
- 移動可能なマスをハイライトし、クリック / タップで進む。
- **UNDO**（1 手戻る）・**REBOOT**（やり直し）対応。
- ドラッグで視点回転・ホイール / ピンチでズーム。

## 使用技術

- **Three.js**（3D 描画）
- HTML / CSS / Vanilla JavaScript
